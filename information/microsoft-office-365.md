## About

Microsoft 365 (formerly Office 365) is free to Swarthmore employees and students. The service includes both downloadable and online versions of Microsoft productivity applications including Microsoft Word, PowerPoint, Excel, and OneNote. You can install Office on up to 5 PCs or Macs, 5 tablets, and 5 smartphones. 

**NOTE:** Swarthmore does not support OneDrive, SharePoint, or Teams. 

Most college owned computers already have Microsoft Office installed. Installing multiple versions of Microsoft Office can cause problems. Remove any old versions before installing Office 365. 

## Downloading Microsoft 365 Apps

Office 365 is now called **Microsoft 365**. 

  1. Go to [m365.cloud.microsoft/apps/](https://m365.cloud.microsoft/apps/).
  2. Enter **Swarthmore email address** on the Microsoft sign-in page. 
     1. If prompted, select **Work or school account**.
     2. Enter Swarthmore password.
     3. Verify with Duo.
  3. Select the **Install apps** button from the dropdown menu.
  4. Select **Microsoft 365 apps** to install the Microsoft 365 productivity applications (Word, Excel, PowerPoint, OneNote, Publisher, Access). 
     1. **Microsoft 365 apps** \- downloads the Office Setup installer (approx. 7 MB).
     2. Microsoft 365 Copilot desktop app - only installs the Copilot companion app.

[![Arrow pointing to the blue Install apps button on the Microsoft 365 Copilot apps page](https://kb.swarthmore.edu/images/6/6e/Microsoft_Office_365_1777657933169.png)](https://kb.swarthmore.edu/wiki/File:Microsoft_Office_365_1777657933169.png)

  
**Note:** The [office.com](http://office.com) site now redirects to the **Microsoft 365 Copilot** app (M365 Copilot). After login with Swarthmore account, you will end up on the **Welcome to Copilot Chat** page. For now, you can still go to **Apps** to find option to **Install apps** > **Microsoft 365 apps**. 

## Mac Troubleshooting

### Mac Office 365 Error - View Only Your Account Doesn't Allow Editing on a Mac

After installing Office 365 apps on a personally owned Mac some users get an error that says: 

    **View Only. Your account doesn't allow editing on a Mac. To learn more, contact your admin about your Office plan**
[!["View Only" message indicating the account does not allow editing on a Mac with a prompt to contact the admin about the Office plan](https://kb.swarthmore.edu/images/8/82/Microsoft_Office_365_1777658007042.png)](https://kb.swarthmore.edu/wiki/File:Microsoft_Office_365_1777658007042.png)

First, verify that you are using the proper account: 

  1. Click **Use Another Account**.
  2. Sign in with your email address and Microsoft password.



Alternately, 

  1. Click the **Activate** button.
  2. Sign in with credentials.



If that does not work, you can attempt to clear credential caches and reactivate Office 365 for the Mac: 

  1. Open **Finder** → click go on the top menu bar → go to folder → input the following path: ~/library/Group Containers/
  2. Right-click each of the folders below if present, and then click move to trash. 
     * ubf8t346g9.ms
     * ubf8t346g9.office
     * ubf8t346g9.officeosfwebhost

[![macOS Finder window showing the Group Containers folder with subfolders UBF8T346G9.ms, UBF8T346G9.Office, and UBF8T346G9.OfficeOsfWebHost selected](https://kb.swarthmore.edu/images/5/59/Microsoft_Office_365_1777658117048.png)](https://kb.swarthmore.edu/wiki/File:Microsoft_Office_365_1777658117048.png)

If that doesn’t work, the last option is to [try uninstalling office](https://support.office.com/en-us/article/troubleshoot-office-for-mac-issues-by-completely-uninstalling-before-you-reinstall-ec3aa66e-6a76-451f-9d35-cba2e14e94c0?ui=en-US&=%2C%2C%2C%2C%2C%2C%2C%2C%2C%2C%2C%2C%2C&rs=en-US&ad=US) for Mac completely then reinstalling and reactivating Office. 

## Collaboration

There may be times when you’d like to collaborate with colleagues in Office 365. Note there are two different versions of Office 365, a cloud version and a desktop version. Both have slightly different capabilities. For example, the desktop version of Word has a style pane which can be useful when changing the look and feel of different elements. You can do the same in the cloud version but it is a bit more complex. 

Here are steps on how to collaborate: 

  1. Share your document with your collaborators. We recommend using their Swarthmore email addresses.
  2. You can switch between desktop and the cloud version of a document by launching it from the cloud version. 
     * From SharePoint/OneDrive 
       1. Go to the [Swarthmore Sharepoint website](https://swarthmore-my.sharepoint.com/) where all of your cloud MS365 documents are stored;
       2. Locate the file you wish to open in a MS365 desktop application;
       3. Hover over the file name to have some buttons appear;
       4. Select the ellipses;
       5. Select Open;
       6. Select Open in [your program].
     * From the document itself 
       1. Have the file open
       2. Click on the Editing button, generally located in the top right corner of the document
       3. Select Open in Desktop
  3. Provided both editors are using an MS365 account, edits and comments are synced automatically similar to the way a Google Doc works.
