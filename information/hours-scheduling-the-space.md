# Hours & Scheduling the Space

## What are the hours?

During the academic year, we are open from 1pm - 11pm Sunday, 9:00am - 11pm Monday - Thursday, 9:00am - 5pm Friday, and 1pm - 5pm Saturday. If you need access beyond those hours, please email a request to Ashley Turner ([aturner2@swarthmore.edu](mailto:aturner2@swarthmore.edu)) or Jeremy Polk ([jpolk1@swarthmore.edu](mailto:jpolk1@swarthmore.edu)) with the duration for which you’ll need access and the reason (class, independent project, etc.) Faculty and staff already have 24/7/365 access with their ID cards.  There is a swipe panel on the door. Check with Ashley or Jeremy if you have questions or concerns. One common student ID issue is using the wrong ID card, such as if you've replaced and then found your original card.  Only the latest card will work.  Faculty need to have a current ID card for this system to work for them. 

## Can I hold my class in here?  Doesn’t the Registrar schedule this room?

If the room is available and your class will use the technology of the Creative Media Commons, then we'd like to welcome you to teach here.  The Registrar does NOT schedule the Creative Media Commons; you'll need to talk with Ashley Turner ([aturner2@swarthmore.edu](mailto:aturner2@swarthmore.edu)) or Jeremy Polk ([jpolk1@swarthmore.edu](mailto:jpolk1@swarthmore.edu)) to arrange a time. Space is available on a first come, first serve basis. Any class using the Creative Media Commons must continue to allow walk-in access to unused computers and printers since this is an open facility. 

## Do I have to let people in when I’m teaching here?

Yes, being an open facility is one of our primary guiding principles in the Creative Media Commons. One of the conditions to using the Creative Media Commons for your classes is that it must be maintained as an open resource for faculty, staff, and students.
