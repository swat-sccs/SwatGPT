## Installation Instructions

To install, download the appropriate file below, unzip, and run the installer. 

Tip: If macOS tells you you cannot run the installer because it is from an "Unidentified Developer", right-click or control-click on the installer and choose **Open** from the pull down menu. 

## Download

Click on the links below to download the installer. 

[Mestrelab Mnova for Windows](https://drive.google.com/file/d/1un3Hx0iCTjuypDTVBRxP6qswd1xay84B/view?usp=drive_link)

## License File

After installation, apply the license files below on the first launch. Computers must be connected to the campus network to use the software. 

[License Files](https://drive.google.com/file/d/1s8D6MAf47hMLha8AKJITEOUALtujccAt/view?usp=drive_link)

To apply new license files on an existing install, download the license files and place them in the following directory: 

Windows: `C:\Program Files\MestReNova\Mestrelab Research S.L.\licenses OR C:\Program Files (x86)\MestReNova\Mestrelab Research S.L.\licenses`

macOS: `/Library/Application Support/Mestrelab Research S.L./Mestrenova/licenses`
