# Gmail and Apple Mail Configuration

Configuring email with Apple Mail in macOS. 

## Add an Account

  1. Make sure your operating system is up to date.
  2. Select the Apple Menu, then select **System Settings**.
  3. In the lefthand sidebar, select **Internet Accounts**. You may need to scroll down to view this option.[![The Internet Accounts tab in System Settings, which lists all active accounts, followed by an Add Account button at the bottom.](https://kb.swarthmore.edu/images/1/10/Screenshot_2025-03-20_at_9.44.09_AM.png)](https://kb.swarthmore.edu/wiki/File:Screenshot_2025-03-20_at_9.44.09_AM.png)
  4. Select **Add Account…**
  5. Select **Google.**
  6. Select **Open Browser**.
  7. Type in your full Swarthmore email address and select **Next**.[![A Sign in With Google window, featuring a blank text field for Email or Phone, followed by options for Create Account or Next.](https://kb.swarthmore.edu/images/5/52/Screenshot_2025-03-20_at_9.48.59_AM.png)](https://kb.swarthmore.edu/wiki/File:Screenshot_2025-03-20_at_9.48.59_AM.png)
  8. On the Swarthmore login screen enter your Swarthmore username and password, then click **Login**.
  9. Authenticate with Duo.
  10. Select the apps you want to use with this account. Click **Done**.  
[![A Google-branded window, reading Select the apps you want to use with this account. Options include mail, contacts, calendars, and notes, followed by Cancel and Done.](https://kb.swarthmore.edu/images/6/6c/Screenshot_2025-03-20_at_9.50.51_AM.png)](https://kb.swarthmore.edu/wiki/File:Screenshot_2025-03-20_at_9.50.51_AM.png)
  11. Close the Internet Accounts window. Your mail is now set up.
