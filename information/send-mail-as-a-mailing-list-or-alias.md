# Send Mail As a Mailing List or Alias

If you are on a departmental mailing list and need to send messages from that list’s address in Gmail, you will need to set the address up as a "Send Mail As" account. 

  1. In Gmail, open **Settings** from the gear menu.
  2. Choose the **Accounts** tab [![Gmail Settings menu, with the Accounts tab open. Here, we can see options to Send Mail As either my user account or a delegated account I have access to. I have the options to Make Default, Edit Info, or Delete each email. I can also Add Another Email Address here.](https://kb.swarthmore.edu/images/b/bb/Screenshot_2025-03-12_at_11.55.21_AM.png)](https://kb.swarthmore.edu/wiki/File:Screenshot_2025-03-12_at_11.55.21_AM.png)
  3. Click **Add another email address**. Enter a descriptive official name for the account and the email address. Keep **Treat as an alias** checked.[![](https://kb.swarthmore.edu/images/1/15/2.jpg)](https://kb.swarthmore.edu/wiki/File:2.jpg)
  4. You will be asked to send a verification email. Click **Send Verification**.[![](https://kb.swarthmore.edu/images/7/79/3.jpg)](https://kb.swarthmore.edu/wiki/File:3.jpg)
  5. The verification email will be sent to the list.  Check your inbox for the email containing the confirmation code.
  6. Enter the **confirmation code** on the confirmation window.[![](https://kb.swarthmore.edu/images/0/03/5.jpg)](https://kb.swarthmore.edu/wiki/File:5.jpg)
  7. Now when composing an email, you will have the option to change the "**From** " address to the alternate email address.[![](https://kb.swarthmore.edu/images/1/18/6.jpg)](https://kb.swarthmore.edu/wiki/File:6.jpg)
