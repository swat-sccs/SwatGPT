# Campus Printer Setup Instructions

How to connect to Swarthmore's networked faculty/staff printers. Find your printer's queue name, model, and location in the "Campus Printer Directory" article, then follow the instructions below that match your operating system and printer model.

## Connecting from Windows

### Applies to: Canon MF1643 II Series PS, Canon Océ ColorWave 500, Canon iR-ADV 4225/4235 PS, Canon iR-ADV 4745/4751 PS, Canon iR-ADV 525 III PS, Canon iR-ADV 6780 PS, Canon iR-ADV 8585/8595 PS, Canon iR-ADV C250/350 PS, Canon iR-ADV C257/357 PS, Canon iR-ADV C3826 PS, Canon iR-ADV C3880/C4580 PS, Canon iR-ADV C3926, Canon iR-ADV C5535/5540 PS, Canon iR-ADV C5840/5850 PS, Canon iR-ADV C5840/5870 PS, Canon iR3235/iR3245 PS, Generic PCL Printer

1. Click your **Start** button.
  2. In the **Search** box, type **\\\swat-print** and press Enter. If prompted for credentials, enter GARNET\username in the username field, and your password.
  3. Find the **printer queue name from the Campus Printer Directory.**
  4. Double-click on the printer (it will install automatically)

## Connecting from macOS

### Applies to: Canon MF1643 II Series PS, Canon Océ ColorWave 500, Canon iR-ADV 4225/4235 PS, Canon iR-ADV 4745/4751 PS, Canon iR-ADV 525 III PS, Canon iR-ADV 6780 PS, Canon iR-ADV 8585/8595 PS, Canon iR-ADV C250/350 PS, Canon iR-ADV C257/357 PS, Canon iR-ADV C3826 PS, Canon iR-ADV C3880/C4580 PS, Canon iR-ADV C3926, Canon iR-ADV C5535/5540 PS, Canon iR-ADV C5840/5850 PS, Canon iR-ADV C5840/5870 PS, Canon iR3235/iR3245 PS, Generic PCL Printer

**Before you Begin:** _Canon drivers are already on College-provided computers. If this is a personal computer, download and install the Mac Printer Drivers first._  _Run the installer. This installer may warn that it cannot open because it is from an unidentified publisher. You can launch the installer by control-clicking on the file and choosing "open"._

  1. Open **System Settings** , select **Printers & Scanners**.
  2. Choose **Add Printer, Scanner, or Fax** add a printer
  3. Click the ![Globe icon](https://kb.swarthmore.edu/images/b/b4/test_1778765212532.png) tab at the top of the **Add Printer** page
  4. In the Address field, type **swat-print**
  5. For Protocol, choose **Line Printer Daemon - LPD**
  6. In the **Queue** field, enter the **printer queue name from the Campus Printer Directory.**
  7. Under **Name** , copy and paste name from **Queue** field.
  8. Under **Use** , select the option for **Select Software...,** and search for **the printer model from the Campus Printer Directory.**
  9. Click **Add**. After you click Add, the Printer list window will reappear with the selected printer added to the list of printers.

## Print Release Station Instructions

This printer has a swipe print release station enabled. Print jobs sent to this printer will queue only print when the sender is in front of the release station and swipes their OneCard or Digital OneCard. Username and password logins on the printer touch screen also work, but swipe release is recommended. 

This print release station is intended to increase print job privacy and also cut down on accidental printing waste. Unclaimed print jobs will expire from the queue if not released within four hours. 

[Print Release FAQ](https://kb.swarthmore.edu/wiki/Print_Release_FAQ "Print Release FAQ")
