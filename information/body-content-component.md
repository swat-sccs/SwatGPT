# Body Content Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

The **Body Content** component allows you to place formatted body text in any page region, which would normally be reserved for the page's **Body** field or a more complex component. 

## Elements

  1. Body (_required_)
