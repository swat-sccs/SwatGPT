# Requesting an Account on Firebird

Requesting an account on Firebird is a two-step process: 

  * First, [create an ed25519 SSH key](https://kb.swarthmore.edu/wiki/Create_an_SSH_Key "Create an SSH Key")
  * Second, [complete this form to request an account](https://support.swarthmore.edu/support/catalog/items/225)
