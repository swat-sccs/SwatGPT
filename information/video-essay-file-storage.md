# Video Essay File Storage

### Personal Hard Drives

Students needing storage for their class video projects should purchase a portable hard drive. Small film and video projects can be easily edited directly from an external hard drive. 

### Google Drive

While it is possible to store media projects on Google Drive, doing so will add unnecessary time to your workflow. It is not possible to edit media files directly from Google Drive - this means that each file would need to be downloaded to a local device before being used in a video edit or animation. This can take many hours for large media files. 

Uploading source files to Google Drive as a backup is perfectly acceptable. Using Google Drive as a location to store and share your final video products is also a good idea.
