# Audio Player Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")  
  
The **Audio Player** component allows for audio playback and display of a provided transcript. This component can only be created and maintained by ITS administrators. 

To request that an **Audio Player** component be added to your site, email [support@swarthmore.edu](mailto:support@swarthmore.edu).
