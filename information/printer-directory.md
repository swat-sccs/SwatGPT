# Campus Printer Directory

Directory of all 189 networked faculty/staff printers at Swarthmore College, grouped by building. To connect from Windows or macOS, or to use a print release station, see the "Campus Printer Setup Instructions" article. Each printer is installed using its queue name on the `swat-print` print server.
