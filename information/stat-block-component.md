# Stat Block Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

The **Stat Block** component displays a simple donut chart visualization representing a single statistic as a percentage. This component can only be created and maintained by ITS administrators. 

To request that a **Stat Block** component be added to your site, email [support@swarthmore.edu](mailto:support@swarthmore.edu).
