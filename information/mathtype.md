## About MathType

MathType is an equation editor for documents, web pages, Moodle, and for TeX, LaTeX, and MathML documents. 

MathType includes [ChemType](https://demo.wiris.com/mathtype/en/chemtype.php), an extension for creating chemical notation. 

MathType will typeset handwritten equations. 

[![Handwritten mathematical formula x squared plus y squared under a square root on a digital whiteboard being converted into a clean, typeset version indicated by a red arrow](https://kb.swarthmore.edu/images/1/1c/MathType_1777581578604.png)](https://kb.swarthmore.edu/wiki/File:MathType_1777581578604.png)

## Versions

MathType is available in different formats: 

  * Google Docs
  * Microsoft Office
  * Moodle



### Google Docs

Follow the [instructions for installing and activating MathType for Google Docs](https://docs.wiris.com/mathtype/en/mathtype-office-tools/mathtype-for-google-workspace.html). This process involves installing the MathType add-on for for Google Docs. Make sure to use your Swarthmore Google account. 

### Microsoft Office

MathType is available as an add-on for Microsoft Office 365 for Windows, macOS, and iPads or as a downloadable program for college-owned Windows computers only. 

[MathType download page](https://store.wiris.com/en/products/mathtype/download)

For the downloadable, Windows only version, use the [license information](https://drive.google.com/open?id=1sMK-6cDZVXNVrqKUXKqP7bsneiINB3Xs) to complete the installation process on a college-owned Windows computer. 

More information on [MathType with Microsoft Office on macOS](https://lp.wiris.com/catalina/). 

### Moodle

There are buttons for MathType and ChemType in every text editor in Moodle. First click to expand the toolbar, then click on the MathType or ChemType icon to insert an equation. 

[![MathType equation editor window open within a text editor toolbar showing MathType and ChemType buttons highlighted](https://kb.swarthmore.edu/images/4/42/MathType_1777581641108.png)](https://kb.swarthmore.edu/wiki/File:MathType_1777581641108.png)

#### Example usage

  * Instructors can use MathType in quiz questions.
  * Students can respond to quiz questions using MathType.
  * Instructors can use MathType in Moodle pages or assignment descriptions
