# Two Column Layout Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

The **Two Column Layout** component allows you to display two components side by side. The **Two Column Layout** component can only be used in the **Full Width Page Content** region. 

Only the following components can be placed inside a **Two Column Layout** component: 

  * [Events Calendar Feed](https://kb.swarthmore.edu/wiki/Events_Calendar_Feed_Component "Events Calendar Feed Component")
  * [Feature Link List](https://kb.swarthmore.edu/wiki/Feature_Link_List_Component "Feature Link List Component")
  * [News Feed](https://kb.swarthmore.edu/wiki/News_Feed_Component "News Feed Component")
  * [RSS Feed](https://kb.swarthmore.edu/wiki/RSS_Feed_Component "RSS Feed Component")



## Elements

The **Two Column Layout** component does not contain any fields of its own. Instead, it serves as a container for the components placed within its two columns.

## Step-by-step Instructions

  1. Add one of the supported components to either column. 
     1. [Events Calendar Feed](https://kb.swarthmore.edu/wiki/Events_Calendar_Feed_Component "Events Calendar Feed Component")
     2. [Feature Link List](https://kb.swarthmore.edu/wiki/Feature_Link_List_Component "Feature Link List Component")
     3. [News Feed](https://kb.swarthmore.edu/wiki/News_Feed_Component "News Feed Component")
     4. [RSS Feed](https://kb.swarthmore.edu/wiki/RSS_Feed_Component "RSS Feed Component")
  2. Add a second supported component to the remaining column.
