# Events Calendar Feed Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

The **Events Calendar Feed** component displays upcoming events from a [Swat Central](https://swatcentral.swarthmore.edu/) feed. This component can only be created and maintained by ITS administrators. 

To request that an **Events Calendar Feed** component be added to your site, email [support@swarthmore.edu](mailto:support@swarthmore.edu).
