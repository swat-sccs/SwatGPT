# Safe Exam Browser Settings Recommendations

# Safe Exam Browser Recommended Settings for in Class Exams in Moodle

We recommend that you use the following settings for Safe Exam Browser (highlighted). Note that you can enter these settings manually, or you can set them up in a configuration file and upload that file for use. You can modify these settings however you wish, and save them as a "config.seb" file, which is just an XML (text) file with the settings detailed, which can then be loaded into other Quizzes you use in a course in Moodle. There are, in fact, many other settings for Safe Exam Browser generally, and you can find them at the [Safe Exam Browser developer site](https://safeexambrowser.org/).
