# Stat Lockup Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

The **Stat Lockup** component is used to display a specific combination of images and text. Because of its specialized layout, it is less flexible than many of the other component types. This component can only be created and maintained by ITS administrators. 

To request that a **Stat Lockup** component be added to your site, email [support@swarthmore.edu](mailto:support@swarthmore.edu).
