# CPSC 075. Compilers

(Cross-listed as [ENGR 023](https://catalog.swarthmore.edu/preview_course_nopop.php?catoid=32&coid=111304))  
This course explores the conversion of programs from source code to executable forms. Topics covered include lexical analysis, formal grammars and parsing, runtime representation decisions, code transformation and generation, and static optimization techniques.  
Group 2 course.  
Prerequisite: [CPSC 031](https://catalog.swarthmore.edu/preview_course_nopop.php?catoid=32&coid=110017) and [CPSC 035](https://catalog.swarthmore.edu/preview_course_nopop.php?catoid=32&coid=110018)   
Natural sciences and engineering.  
Lab work required.  
1 credit.
