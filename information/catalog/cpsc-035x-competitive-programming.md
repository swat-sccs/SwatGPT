# CPSC 035X. Competitive Programming

CPSC 035X is an attachment to CPSC035 for students who wish to strengthen their foundation in data structures and C++ programming. Topics will include Input/Output, applications of data structures including Lists, Dictionaries, Stacks and Queues, debugging, and graph algorithms. Each week students will work on problem sets consisting of competitive programming style coding problems.  
  
  
Prerequisite: Students must be currently enrolled in [CPSC 035](https://catalog.swarthmore.edu/preview_course_nopop.php?catoid=32&coid=110018) and must apply for admission.
