# PEAC 071B. Research Seminar: Global Nonviolent Action Database

(Cross-listed as [SOCI 071B](https://catalog.swarthmore.edu/preview_course_nopop.php?catoid=32&coid=111261))  
This one-credit research seminar involves contributing to The Global Nonviolent Action Database at Swarthmore College. See [https://nvdatabase.swarthmore.edu](https://nvdatabase.swarthmore.edu/) Each year, hundreds of thousands of users access the database, which contains crucial information on nonviolent campaigns, including those for human rights, democracy, environmental justice, economic justice, national/ethnic representation, and peace. Each student will investigate several campaigns and prepare them for publication in the database. Together, we will draw strategic lessons from social scientific literature and from what the group is learning while researching people's struggles.
