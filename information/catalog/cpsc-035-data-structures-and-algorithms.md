# CPSC 035. Data Structures and Algorithms

This course completes the broad introduction to computer science begun in [CPSC 021](https://catalog.swarthmore.edu/preview_course_nopop.php?catoid=32&coid=110016). It provides a general background for further study in the field. Topics to be covered include object-oriented programming in C++, advanced data structures (trees, priority queues, hash tables, graphs, etc.) and algorithms, and software design and verification. Students will be expected to complete several programming projects illustrating the concepts presented.  
Prerequisite: [CPSC 021](https://catalog.swarthmore.edu/preview_course_nopop.php?catoid=32&coid=110016) or equivalent. Discrete Mathematics is recommended.
