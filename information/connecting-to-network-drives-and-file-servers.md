# Connecting to Network Drives and File Servers

ITS maintains network drives and file servers to store research and departmental data. This page contains instructions for connecting these drives to your computer. 

  


## Windows (college-owned)

  1. Right-click Windows icon in the bottom-left corner
  2. Go to **Run**
  3. In the box, type `\\<name of server>.swarthmore.edu`



## Windows (personal computer)

  1. Right-click Windows icon in the bottom-left corner
  2. Go to **Run**
  3. In the box, type `\\<name of server>.swarthmore.edu`
  4. Log onto server with your Swarthmore credentials 
     1. Type your user name as `garnet\<your user name>`



## macOS (college-owned or personal)

  1. Click **Finder**
  2. Click on **Go** in the top menu bar
  3. Click **Connect to Server** in the drop-down list
  4. In the Server Address box, type `smb://<name of server>.swarthmore.edu`
  5. Type `garnet\<your user name>` and your Swarthmore password when prompted
  6. Click connect
