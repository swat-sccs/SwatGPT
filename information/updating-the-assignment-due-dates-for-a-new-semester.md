# Updating the assignment due dates for a new semester

After importing a course from a previous semester, all the due dates for assignments and other activities will be incorrect. It is possible to update all the dates for the class from the **Dates Report**. 

To access this report: 

  1. Go to the course main page and click **Reports** (under course title)** → Dates**.
  2. Adjust the dates for each activity as needed.
  3. Click **Save changes** when finished.
