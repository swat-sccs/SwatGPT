# Record Video Using Panopto Capture With Web Browser

Panopto Capture allows you to easily record audio, video, and screens or applications within your web browser. A user can access Panopto Capture directly within their browser instead of downloading the desktop application. 

Panopto has a robust support page. To record videos with Panopto Capture from your web browser, follow the instructions from links below. 

  * <https://support.panopto.com/s/article/How-to-Create-a-Video-Using-Panopto-Capture>
  * <https://support.panopto.com/s/article/How-to-Create-a-Video-Using-Panopto-Capture-with-Safari>
  * <https://support.panopto.com/s/article/Create-High-Quality-Recordings>



### Note

  * You must have "Creator" role access or greater to use this feature. If you do not, please reach out to [support@swarthmore.edu](mailto:support@swarthmore.edu) to make a request.
  * You must have the latest version of Chrome, Firefox, and Edge to access this feature. _Please note: Safari 15.0+ users, please refer to[How to Create a Video Using Panopto Capture with Safari](https://support.panopto.com/s/article/How-to-Create-a-Video-Using-Panopto-Capture-with-Safari), as options are different for Safari users._
  * Please make sure anti-virus exceptions are made for audio (microphone), video (web camera), and screen in your preferred browser.
