# Uploading Assignment Feedback Files

Moodle assignments are a good way to keep track of student submitted files. It is also possible to mark up student files and upload the marked files to Moodle in order to provide feedback to students. 

There are two ways to do the process - one at a time or in bulk. 

In order to upload a feedback file, the Feedback file option must be selected in the settings for the assignment 

## One at a time

  1. Click on the assignment in your Moodle course and then click on the **View All Submissions** button.
  2. Click on the **Grade** button for the student work you wish to grade.
  3. Download the file submission by clicking on the filename of the submission located near the top right of the grading column.
  4. Markup the file using your editor of choice
  5. After you've marked up the file, upload the file to the **Feedback Files** area.
  6. Make sure to save changes before leaving the page.



## In bulk

The fastest way to download and mark up assignments is by using the bulk options. 

  1. Click on the assignment in your Moodle course and then click on the **View All Submissions** button.
  2. Unless you have students submitting multiple files, scroll down to the bottom of the page and uncheck **Download submissions in folders**.
  3. Scroll back to the top of the page and select **Grading Action → Download all Submissions**.
  4. Moodle will download a zip file containing all the student file uploads.
  5. Unzip the file and markup files as needed. **Do not change the file names**.
  6. When done grading, zip the marked up files.
  7. Go back to the **View all submissions** page. At the top of the page select **Grading Action → Upload Multiple Feedback files in a zip**.
  8. Moodle will use the filenames to associate the feedback file with each student.
