## About Make Me Admin

This tool gives non-admin users the ability to install software in Admin mode temporarily, while letting you run as a ‘normal’ user the rest of the time. 

## Requires OS Versions

Windows 10 or higher 

## How to use Make Me Admin on Campus Windows computers

  1. Launch **Make Me Admin** from the Start menu. Select the **Start** menu, scroll down and click **Make Me Admin** from the list of Apps. [!["Make Me Admin" application highlighted in the Windows Start menu under the M section](https://kb.swarthmore.edu/images/e/e6/Make_Me_Admin_1777581161547.png)](https://kb.swarthmore.edu/wiki/File:Make_Me_Admin_1777581161547.png)
  2. When the application launches, it will determine whether you already have administrator rights. 
     1. If you do NOT already have administrator rights, the **Grant Me Administrator Rights** button will be enabled.
     2. If you DO already have administrator rights, that button will be disabled, and the **Remove my Admin Rights** button will be enabled.
  3. Click the **Grant Me Administrator Rights** button. The application will attempt to add you to the Administrators group on your computer. If this process is successful, the application window will disappear, and a new icon will be added to the notification area on the taskbar, near the date and time. A popup message will appear for a few seconds, indicating that you have been added as a Member to the Administrators group. [![Notification stating membership in the Administrators group with an information icon](https://kb.swarthmore.edu/images/d/dd/Make_Me_Admin_1777581201403.png)](https://kb.swarthmore.edu/wiki/File:Make_Me_Admin_1777581201403.png) **Note:** This icon will remain in the notification area as long as your administrator rights are active.
  4. You should now be able to perform administrator task(s): changing computer settings, installing or updating software, etc. 
     1. If you receive a prompt from User Account Control to log in, enter your user name and password. (garnet\username) [![Windows prompt requesting admin username and password for domain garnet with options to select Yes or No](https://kb.swarthmore.edu/images/3/3d/Make_Me_Admin_1777581235478.png)](https://kb.swarthmore.edu/wiki/File:Make_Me_Admin_1777581235478.png)
  5. You have 15 minutes as an Administrator to change your device settings, install or update a program, etc. After the 15 minutes, Make Me Admin will display one final popup message stating you are no longer a member of the Administrators group, and then close completely. 
     1. **Note:** You only need Administrator rights to start an install or update a program. Your install or update will continue to run even after you have been removed from the Administrator group.
  6. Repeat Steps 1-5 as needed to change computer settings or install or update software.
