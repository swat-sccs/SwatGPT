## Windows Computer System Information

### RAM, processor, hard drive storage, and operating system information in Windows 10

  1. Select the **Start** button (bottom-left corner)
  2. Go to **Settings** (gear icon)
  3. Go to **System**
  4. Go to **About** (bottom of left-side navigation) for processor, RAM, and operating system information

### Hard drive storage information in Windows 10

  1. Select the **Start** button (bottom-left corner)
  2. Go to **Settings** (gear icon)
  3. Go to **System**
  4. Go to **Storage** in left-side navigation for hard drive information



[Image of Windows 10 Storage window](https://attachment.freshservice.com/inline/attachment?token=eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJpZCI6MTQwMTIwMzQzNjQsImRvbWFpbiI6InN3YXJ0aG1vcmVpdHMuZnJlc2hzZXJ2aWNlLmNvbSIsInR5cGUiOjF9.qMjyiwvcpndE4ruXRc_VQkwK9DI0XQ83I8ilBPWIPtc) Storage section of Windows system settings displays hard drive information including amount used and how much remains free. 

## Apple Computer System Information

### RAM, processor, and operating system information in macOS

  1. Click on the Apple icon  in the top-left corner of your screen,
  2. Choose **About This Mac**.
  3. You should see the macOS name, such as macOS Big Sur, followed by its version number. The **Overview** tab includes **Memory** (RAM) and **Processor** information.



[Image of About This Mac window](https://attachment.freshservice.com/inline/attachment?token=eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJpZCI6MTQwMTIwMzE3MzQsImRvbWFpbiI6InN3YXJ0aG1vcmVpdHMuZnJlc2hzZXJ2aWNlLmNvbSIsInR5cGUiOjF9.SaVEdmxj2UJqtbrm7ni6HYXw2wRe7XdEegLqEWA1UnM) Overview tab of About This Mac lists Mac version, processor, memory (RAM), graphics card, and serial number. 

### Hard drive storage information in macOS

  1. Click on the Apple icon  in the top-left corner of your screen,
  2. Choose **About This Mac**.
  3. You should see the macOS name, such as macOS Big Sur, followed by its version number. The **Overview** tab includes **Memory** (RAM) and **Processor** information.
  4. Go to the **Storage** tab for hard drive information



[Image of Macintosh HD Storage window](https://attachment.freshservice.com/inline/attachment?token=eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJpZCI6MTQwMTIwMzM3MjUsImRvbWFpbiI6InN3YXJ0aG1vcmVpdHMuZnJlc2hzZXJ2aWNlLmNvbSIsInR5cGUiOjF9.rYt-8r-yBLN90Rbpw7KEXlQu5FaY4BzUzZZzFFFbE-0) Storage tab displays hard drive size and available space. Manage button allows you to free up space.
