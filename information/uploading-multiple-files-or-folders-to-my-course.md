# Uploading multiple files or folders to my course

To upload multiple files to a Moodle course, either create a folder in Moodle and drag files from your computer to the folder, or drag a .zip file from your computer to the main course page and unzip the files. 

## Create a folder

If you want to upload multiple files and put them in a Moodle folder, follow the process below: 

  1. On the Moodle course page, click the **Edit Mode** button to turn editing on.
  2. From the bottom of a section, click **Add an activity or resource** and select **Folder**.
  3. Provide a title and then drag and drop individual files from your computer into the **Content** area.  It is possible to drag multiple files at once.
  4. Click Save at the bottom of the page.



## Upload a .zip file

To mass upload a set of files with sub-folders, create a .zip file with the desired content on your computer. 

To upload the .zip file and have Moodle convert it to a folder: 

  1. On the Moodle course page, click the **Edit Mode** button to turn editing on.
  2. Drag the .zip file from your computer to the desired topic or week in Moodle.
  3. Moodle will ask if you want to extract the .zip file into a folder. Confirm this choice.
  4. A new folder with your files will appear in the topic.
