# Do I have the right version of Word for Mac to use the Accessibility Checker?

If you are using a Mac, you will need to have a recent version of Microsoft Word for Mac (2016 or higher). The previous versions for Mac do not have the Accessibility Checker. 

# How to Determine What Version You Have

To find out what version you have, go to **Word** in the top navigation bar, then **About Microsoft Word**. In that dialog box, look for **Version**. The version should start with 16 or higher; e.g., 16.16.9. **License** should have the year 2016 or later, or mention Microsoft Office 365. 

[![About Microsoft Word selected from the menu. The dialog box is popped out, and the version and license on that screen are indicated.](https://kb.swarthmore.edu/images/3/3f/Word-MacWordVersion.jpg)](https://kb.swarthmore.edu/wiki/File:Word-MacWordVersion.jpg)

## How Do I Upgrade?

If you don't have the right version, visit the [Microsoft Office 365](https://kb.swarthmore.edu/wiki/Microsoft_Office_365 "Microsoft Office 365") software page in the Swarthmore Knowledge Base. Follow the directions there, and if you run into any issues with the installation, [contact the ITS Help Desk](mailto:support@swarthmore.edu).
