# RSS Feed Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

The **RSS Feed** component displays recent posts from an external RSS feed. This component can only be created and maintained by ITS administrators. 

To request that an **RSS Feed** component be added to your site, email [support@swarthmore.edu](mailto:support@swarthmore.edu).
