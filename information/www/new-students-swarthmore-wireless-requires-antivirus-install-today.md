# Swarthmore wireless requires antivirus, install today

This message was sent by Christina Webster, Help Desk Supervisor on August 12, 2022

Greetings Class of 2026,

The campus network requires all computers to have an active, up-to-date antivirus program installed.  **Prepare your computer before coming to Swarthmore campus** so that it is not quarantined, and blocked from the internet.

**Windows 10 and Windows 11 computers** include Windows Security for antivirus - no need to install a separate antivirus program. To update the built-in antivirus, install Windows updates.  To install Windows Updates, go to Settings > Updates and Security > Windows Update.

**Mac computers need antivirus installed**.  Both free and paid-for antivirus applications are allowed.  Some commonly used free antivirus applications include Avast, AVG, Avira, and Bitdefender.

Over the next two weeks, ITS will be sending more information about getting connected to Swarthmore resources. Keep checking your email for further updates.
