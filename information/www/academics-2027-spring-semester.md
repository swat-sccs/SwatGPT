# 2027 Spring Semester

| Date | Event |  | 
|---|---|---|
| January 16 | Residence halls open at 9 a.m. |  | 
| January 17 | Meal plan starts at dinner. |  | 
| January 18 | Martin Luther King Jr (MLK) Day Holiday.  No classes are held on MLK Day. Courses that meet once a week on Mondays may, at the discretion of the instructor, be rescheduled for Monday, May 4th. |  | 
| January 19 | Classes begin. |  | 
| February 1 | Drop/add ends. Last day to delete a course from or add one to permanent registration. Last day to uncover a shadow grade for a CR course from the previous semester. |  | 
| February 22 | All outstanding incompletes from Fall semester must be complete and graded. |  | 
| March 5 | Final examination schedule available online. |  | 
| March 5 | Spring Break begins after last class. |  | 
| March 15 | Spring classes resume at 8:30 a.m. |  | 
| March 24 | Schedule of courses and seminars for next semester available online. |  | 
| March 26 | Last day to declare CR/NC grading option. Last day to withdraw from a course and receive the grade "W." |  | 
| April 1 | Note: All accounts must show a $0 or positive balance to enroll and select a room for the fall semester. |  | 
| March 29–April 9 | Advising period. |  | 
| April 13-15 | Pre-enrollment for fall semester. |  | 
| April 30 | Classes and seminars end, as originally scheduled. |  | 
| May 6-13 | Course Final & Honors written examinations. If you must make travel arrangements before the examination schedule is published, do not expect to leave until after finals. |  | 
| May 14 | Meal plan ends at dinner for all but seniors. |  | 
| May 14 | Residence halls close to all but seniors at 5:00 p.m. (Non-seniors are expected to leave the College within 24 hours after their last examination.) |  | 
| May 16–18 | Honors orals |  | 
| May 18 | Faculty Deadline for Senior Grades Due, Tuesday noon. |  | 
| May 18 | Senior Deadline for CR Shadow Grade Uncovering, Tuesday 11:59PM. No extensions. |  | 
| May 22 | Baccalaureate |  | 
| May 23 | Commencement |  | 
| May 24 | Residence halls close. |  | 
| May 27 | Faculty Deadline for All Spring Grades Due. See May 19 for grade deadline for Seniors. |  | 
| May 27-30 | Alumni Weekend |  | 
| May 27 | Faculty Deadline for All Spring Grades Due |  |
