# Edit the Job Description

- 
	Visit JobX
- Click "Student Employment Supervisor Home Page."
- Click "JobX Login"
- Use the drop down menu to the right of your job title and choose, "Edit Job"
- Edit the field you wish
- Submit the changes
- Some changes will require approval and if so, your job will move to the status, "Pending Approval"
