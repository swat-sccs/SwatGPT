# Setting a Course Image

To make a course stand out on the Moodle home page, it is possible to upload an image for the course thumbnail. When viewing the Moodle Dashboard in the card or summary view, the image will be shown. If you don't set an image, Moodle picks a default abstract image. Learn more about the course overview listing on our [Moodle Dashboard help page](https://kb.swarthmore.edu/wiki/Moodle_Dashboard "Moodle Dashboard").

## Instructions

Go to your course and click the **Settings** link below the course title. 

Go to the **Description** section and upload your image to the **Course image** section. 

Save the updated setting and go to your [course listing](https://moodle.swarthmore.edu/my/courses.php) to see the results
