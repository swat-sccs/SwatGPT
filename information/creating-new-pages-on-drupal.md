# Creating New Pages On Drupal

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

This section covers creating new pages in Drupal. There are three types of pages that can be created: 

  * **Standard Pages** — The most common page type used throughout the website. Standard Pages are appropriate for most content.
  * **News Pages** — Intended for [news stories](https://kb.swarthmore.edu/wiki/Specialized_Content#9.2_News "Specialized Content") that are syndicated to [News Feed components](https://kb.swarthmore.edu/index.php?title=News_Feed_Components&action=edit&redlink=1 "News Feed Components \(page does not exist\)"). News Pages include additional fields such as Author, Post Date, Thumbnail, Abstract, and Related Stories. They are used primarily by the Communications Office (and some departments) that publish their own news.
  * **News Links** — A specialized page type used to syndicate external (non-Drupal) news stories to a News Feed component. News Links are typically created only by the Communications Office.



## 3.1 Creating Standard Pages

  1. Click **Site Settings** in the Drupal toolbar.
  2. Click **Add Standard Page**.



[![Screenshot showing the Site Settings menu with the Add Standard Page option.](https://kb.swarthmore.edu/images/8/82/top_menu1.png)](https://kb.swarthmore.edu/wiki/File:top_menu1.png)

**Figure:** Select **Add Standard Page** from the Site Settings menu.

The page editor will open with all fields blank. Complete the fields as needed: 

  1. **Title** — Required.
  2. **Subtitle** — Optional.
  3. **Primary Image** — Optional.
  4. **Body** — The main page content.
  5. **Components** — Optional page components.
  6. **Publishing State** — Save the page as either **Draft** or **Published**.
  7. Click **Save**.



Congratulations! You have created a new page in Drupal. 

[![Screenshot of the Standard Page editor showing the available editing fields.](https://kb.swarthmore.edu/images/8/84/new_page_editor.png)](https://kb.swarthmore.edu/wiki/File:new_page_editor.png)

**Figure:** Complete the fields in the Standard Page editor before saving.

The example below compares the editor with the resulting webpage. 

[![Screenshot of the Standard Page editor populated with content.](https://kb.swarthmore.edu/images/4/48/newpage_example1.png)](https://kb.swarthmore.edu/wiki/File:newpage_example1.png)

**Figure:** A completed Standard Page in the editor.

## 3.2 Creating News Pages

Important

News Pages will **not** appear in a News Feed component until they have been tagged by the Communications Office. If you have questions about News Pages, contact [web-update@swarthmore.edu](mailto:web-update@swarthmore.edu).

  


  1. Click **Site Settings** in the Drupal toolbar.
  2. Click **Add News Page**.



[![Screenshot showing the Site Settings menu with the Add News Page option.](https://kb.swarthmore.edu/images/e/e2/top_menu_add_news_page.png)](https://kb.swarthmore.edu/wiki/File:top_menu_add_news_page.png)

**Figure:** Select **Add News Page** from the Site Settings menu.

  1. Confirm that the **Page Layout** is set to **Standard News**.
  2. Add a **Title**.
  3. Add an optional **Subtitle**.
  4. Add an optional **Primary Image**.
  5. Add content to the **Body** field.
  6. Add an optional **News Label**.
  7. Add an attribution in the format **by Author Name**.
  8. Add a **Thumbnail Image** (if different from the Primary Image).
  9. Add optional **Related Stories**.
  10. Add optional **Components**.
  11. Save the page as either **Draft** or **Published**.
  12. Click **Save**.



[![Screenshot of the News Page editor showing the additional news-specific fields.](https://kb.swarthmore.edu/images/b/bc/news_page_1.png)](https://kb.swarthmore.edu/wiki/File:news_page_1.png)

**Figure:** News Pages include additional fields used for syndication and display.

## 3.3 Creating News Links

Important

News Links will **not** appear in a News Feed component until they have been tagged by the Communications Office. If you have questions about News Links, contact [web-update@swarthmore.edu](mailto:web-update@swarthmore.edu).

  


  1. Click **Site Settings** in the Drupal toolbar.
  2. Click **Add News Link**.



[![Screenshot showing the Site Settings menu with the Add News Link option.](https://kb.swarthmore.edu/images/d/d5/top_menu_add_news_link.png)](https://kb.swarthmore.edu/wiki/File:top_menu_add_news_link.png)

**Figure:** Select **Add News Link** from the Site Settings menu.

  1. Add a **Title**.
  2. Enter the URL of the external website.
  3. Add a **Label** to provide context for readers. For News Links, this is typically the name of the publication or website.
  4. Add a **Thumbnail Image**.
  5. Save the News Link as either **Draft** or **Published**. Note that News Links will not appear in a News Feed component until they have been published.
  6. Click **Save**.



[![Screenshot of the News Link editor showing the required fields.](https://kb.swarthmore.edu/images/4/41/add_news_link2.png)](https://kb.swarthmore.edu/wiki/File:add_news_link2.png)

**Figure:** Complete the News Link fields before saving.
