## About

NVDA (**N** on**V** isual **D** esktop **A** ccess) is a free and open source screen reader for computers running Windows. "NVDA allows blind and vision impaired people to access and interact with the Windows operating system and many third party applications." For more information visit the [NV Access website](https://www.nvaccess.org/about-nvda/).

## Getting Started

Start NVDA by pressing control+alt+n, or choosing NVDA from the NVDA menu under Programs on the Start Menu. 

[NVDA User Guide](https://www.nvaccess.org/files/nvda/documentation/userGuide.html)
