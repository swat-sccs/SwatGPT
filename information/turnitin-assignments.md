# Turnitin Assignments

## Creating a Turnitin Assignment

Turnitin assignments are added from the Activities list when you add an activity or resource. From the course home page, start by turning editing on. 

To add a Turnitin assignment follow these steps: 

  1. Click "**Add activity or resource"** in the section you choose. Then select **Turnitin Assignment** from the Activities pop up menu  
[![Turnitin Assignment icon in context among other activity icons](https://kb.swarthmore.edu/images/7/79/Turnitin_Assignment_in_cotnext.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Assignment_in_cotnext.png)
  2. On the New External Tool creation page, enter the Activity name and description (Optional).  
[![](https://kb.swarthmore.edu/images/8/8f/Turnitin_NewExternalTool.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_NewExternalTool.png)
  3. Make any Grade and assignment category settings before moving on to the next step.
  4. Click on Select Content at the top, or on the gear icon (later, after clicking Save) to set up the Turnitin Submission and Similarity Report settings:  
[![Green arrow pointing to Select Content button to get into detailed Turnitin settings](https://kb.swarthmore.edu/images/8/8f/Turnitin_NewExternalTool.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_NewExternalTool.png) OR[![Green arrow pointing to gear icon to get into Turnitin detailed settings for Turnitin Assignment](https://kb.swarthmore.edu/images/b/b8/Turnitin_Assignment_Settings.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Assignment_Settings.png)



  1. Set the Assignment Title, enter instructions, and set the start and due dates for the assignment. Specific times are also selected. Students are only able to submit once the start date and time has passed. After the due date and time, students will be blocked unless late submissions are enabled. You must select a post date for the assignment. The post date comes after the due date and determines when marked papers or grades will be available for student view. To allow late submissions, see the next step.  
[![Image of page with fields to set assignment title, instructions, start date, due date and feedback release date](https://kb.swarthmore.edu/images/1/13/Turnitin_Select_Content.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Select_Content.png)
  2. [![Image with green arrow pointing to link for Optional settings for the Turnitin assignment](https://kb.swarthmore.edu/images/9/94/Turnitin_Optional_Settings.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Optional_Settings.png)Click on Optional Settings to configure the similarity report access, paper storage and other details of the Turnitin system:  

  3. [![image of drop-down menu with choices for student papers to be submitted to the standard Turnitin paper repository, or to not store student papers](https://kb.swarthmore.edu/images/a/af/Turnitin_Paper_Storage_Options.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Paper_Storage_Options.png)Choose whether student papers will be stored on Turnitin's repository or not.  




  1. Click the the appropriate checkbox to allow late submissions (after the due date)  
[![Image with circle around the checkbox and text to allow students to submit assignments late \(after the due date\)](https://kb.swarthmore.edu/images/9/9d/Turnitin_Late_Submissions.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Late_Submissions.png)
  2. Choose when similarity reports are generated:[![Image with drop down open showing similarity report timing options](https://kb.swarthmore.edu/images/0/00/Turnitin_SImilarity_Report_Settings.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_SImilarity_Report_Settings.png)
  3. Choose whether or not students are allowed to view Similarity Reports for their submissions by selecting yes or no from the Display Similarity Reports to Students option.[![Image showing checkbox allowing students to view similarity reports checked](https://kb.swarthmore.edu/images/5/58/Turnitin_Simlarity_Report_details.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Simlarity_Report_details.png)  

  4. If you wish to add a rubric use the Rubric Manager under the GradeMark Options.[![Image showing drop-down when Attach a rubric is checked with button to launch Rubric Manager](https://kb.swarthmore.edu/images/b/b2/Turnitin_Rubric_attachment.png)](https://kb.swarthmore.edu/wiki/File:Turnitin_Rubric_attachment.png)
  5. Once finished modifying other assignment options, click Submit to add the Turnitin assignment to the course.



## Using Turnitin for individual papers

Ts possible to submit individual papers for assessment by Turnitin outside of Moodle. See [Turnitin Outside of Moodle](https://kb.swarthmore.edu/wiki/Turnitin_Outside_of_Moodle "Turnitin Outside of Moodle") for more informations.
