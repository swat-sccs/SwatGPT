# Turnitin Outside of Moodle

When evaluating a small number of papers or for work created outside of Moodle, it may be more convenient for faculty to access Turnitin tools directly. Faculty can request an account to Turnitin’s [Feedback Studio](https://help.turnitin.com/feedback-studio/turnitin-website/instructor/instructor-category.htm) by submitting a help ticket with ITS. This allows professors to submit student work for originality checks outside of the Moodle. 

For more information see instructions for using [Turnitin Feedback Studio](https://help.turnitin.com/feedback-studio/turnitin-website/instructor/instructor-category.htm) or view general [Turnitin help pages](https://guides.turnitin.com/hc/en-us/articles/24008452116749-Welcome-to-Turnitin-Guides). can be found in Turnitin's Guide System: <https://help.turnitin.com/feedback-studio/turnitin-website/instructor/instructor-category.htm>. 

## Usage

For faculty who need to check student work outside the context of an assignment in Moodle, the specific tool to use is **Quick Submit**.
