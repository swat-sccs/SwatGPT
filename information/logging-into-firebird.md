# Logging into Firebird

Once you have [requested an account](https://kb.swarthmore.edu/wiki/Requesting_an_Account_on_Firebird "Requesting an Account on Firebird"), several methods are available to connect to Firebird: 

  * [Mac / Linux Terminal Access](https://kb.swarthmore.edu/wiki/Mac_/_Linux_Terminal_Access "Mac / Linux Terminal Access")
  * [Windows Terminal Access](https://kb.swarthmore.edu/wiki/Windows_Terminal_Access "Windows Terminal Access")
  * [Open OnDemand](https://kb.swarthmore.edu/wiki/Open_OnDemand "Open OnDemand")
