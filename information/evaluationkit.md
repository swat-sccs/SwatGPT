## Description

EvaluationKit is an online course evaluation service with configurable questions, flexible options, and extensive reporting. 

Because it takes some time to write, configure, and distribute the survey, it is best for department-wide surveys or similar course evaluations used by multiple instructors. Once set up, it can be used within Moodle or as a separate site. Contact your [Academic Technologist](https://www.swarthmore.edu/its/academic-technology-staff) for more information about getting started with EvaluationKit.
