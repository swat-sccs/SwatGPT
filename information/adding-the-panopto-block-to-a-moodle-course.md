# Adding the Panopto Block to a Moodle Course

Follow these steps to activate the Panopto Block in a Moodle course: 

  1. Go to your course and turn editing on.
  2. If the block drawer column isn't visible, show it using the **Open Block Drawer **button [![](https://kb.swarthmore.edu/images/f/fc/image2023-7-12_9-57-48.png)](https://kb.swarthmore.edu/wiki/File:image2023-7-12_9-57-48.png) on the top right of the screen.
  3. Click **Add a Block**
  4. Select **Panopto** , wait a few moments and the block will appear in the Block Drawer menu
  5. Click on **Provision Course** and look for a message _“Successfully provisioned course with id: [a long string of numbers and letters - each course will have a different set of numbers and letters]”_  


[![](https://kb.swarthmore.edu/images/8/85/Integrating_Moodle_Zoom_and_Panopto_-_Google_Docs.png)](https://kb.swarthmore.edu/wiki/File:Integrating_Moodle_Zoom_and_Panopto_-_Google_Docs.png)

The addition and provisioning of the block are critical as this is what allows Panopto to automatically link to any recordings you make for your course
