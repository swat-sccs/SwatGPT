# Moodle Blocks

It is possible to display additional information about your course on the right hand column.  These boxes are called **blocks** and the right hand column is called the **block drawer**.  If the block drawer column isn't visible, show it using the **Open Block Drawer** button: 

[![Moodle Block drawer icon](https://kb.swarthmore.edu/images/f/fc/image2023-7-12_9-57-48.png)](https://kb.swarthmore.edu/wiki/File:image2023-7-12_9-57-48.png)

on the top right of the screen. 

## Adding Blocks

To add a block to your Moodle course, go into edit mode and click the **Add a block** link at the top of the block drawer then select the block to add. The block will appear at the bottom of the block drawer. 

## Removing Blocks

It is possible to remove a block by turn on edit mode, clicking on the gear icon in the block, then selecting delete. 

## Moving Blocks

In editing mode, it is possible to adjust the order of the blocks. Click on the four-way arrow icon and drag the block to the desired position.
