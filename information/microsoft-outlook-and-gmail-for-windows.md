# Microsoft Outlook and Gmail for Windows

Configuring email and calendar with Outlook in Windows using Google Apps Sync. 

Ensure you are using the most recent version of Outlook and your operating system is up to date. 

## Add a Gmail Account to Outlook

### On Windows

  1. Download the **Recommended for users** EXE file from the [Google Workspace Sync for Outlook download page](https://tools.google.com/dlpage/gssmo).
  2. On the computer where you use Outlook, open the installer and follow the instructions.
  3. Move to [Sign in to your Google Account](https://support.google.com/a/users/answer/153872).
  4. For best results, set the mailbox size to unlimited. Find the Google Workspace Sync tool in your task bar and right click it. Choose “Set Mailbox Size”, and set it to “Unlimited”.

[![mailbox size.JPG](https://kb.swarthmore.edu/images/0/0e/mailbox_size.JPG)](https://kb.swarthmore.edu/wiki/File:mailbox_size.JPG)

### **On MacOS**

  1. Select **Outlook > Preferences > Accounts**
  2. Click the plus (+) sign > **New Account**
  3. Type your email address > **Continue**
  4. Type your password > **Continue**
  5. Click **Continue**
  6. Select an account to sign in.
  7. Allow permissions from Microsoft apps & services
  8. Click **Open Microsoft Outlook**
  9. Select **Done**



For more information, check out the [official Microsoft documentation](https://support.microsoft.com/en-us/office/add-a-gmail-account-to-outlook-70191667-9c52-4581-990e-e30318c2c081#PickTab=Outlook_for_Windows).
