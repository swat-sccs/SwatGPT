# Transferring files with Open OnDemand on Firebird

Open OnDemand provides a helpful file browser, which shows a list of your files on Firebird and makes it straightforward to manage them. It is possible to upload and download files as well as view and edit text files, which can be handy for simple changes. 

To access the file browser, from the top menu bar, click **Files** → **Home Directory**

Alternatively, click on the Home Directory tile from the main landing page:
