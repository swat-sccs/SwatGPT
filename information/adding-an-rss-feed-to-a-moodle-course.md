# Adding an RSS feed to a Moodle Course

Some faculty members find it useful to include an RSS feed in their Moodle courses. These can be from Swarthmore hosted sites (e.g. a WordPress course site) or from other publicly available sources. 

  1. Log into the Moodle course and turn editing on
  2. In the Block Drawer on the right side of the page, click **Add a Block**.  If the right side Block Drawer isn't visible, click the "less-than" button (Open Block Drawer) on the top right of the page.
  3. Choose **Remote RSS feeds** from the dropdown.
  4. The Block settings dialog will open
  5. Make your choices from the options here including: 
     1. Whether to display each link's description
     2. Max number of entries to show per block
     3. Which feeds you would like to make available in the block (Click the "Add/edit feeds" link to add or change feeds.)
     4. Title of the block
     5. Whether a link to the original site should be displayed
  6. Save Changes
