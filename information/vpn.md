## About VPN

For security and privacy reasons, some computing resources are only available when on Swarthmore's campus network. Running Virtual Private Network (VPN) software allows users to access these resources when off campus. 

## Installation Instructions

For more information about VPN and detailed instructions, visit [Swarthmore's VPN and Off-Campus Access page](https://kb.swarthmore.edu/wiki/VPN_and_Off-Campus_Access "VPN and Off-Campus Access").
