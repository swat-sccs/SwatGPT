# Use Microsoft's Accessibility Checkers

Microsoft has made great strides toward accessibility. Many Microsoft programs include accessibility checkers. The steps for most Microsoft programs are included in this how-to. 

## Step-by-Step Guide

  1. Navigate to the **Review** menu or tab.  
[![Word's Review menu shown](https://kb.swarthmore.edu/images/2/2d/Word_Review_Menu.png)](https://kb.swarthmore.edu/wiki/File:Word_Review_Menu.png)
  2. Select **Check Accessibility**.  
[![Check Accessibility button indicated on Review Menu](https://kb.swarthmore.edu/images/f/f3/Word_Review_Menu_CheckAccessibilitySelected.png)](https://kb.swarthmore.edu/wiki/File:Word_Review_Menu_CheckAccessibilitySelected.png)
  3. Click through issues to resolve them in the **Accessibility Pane** , which will also include **steps to fix the issues** and reasons to fix the issues.  
[![Accessibility pane showing inspection results. One warning is showing: Check reading order.](https://kb.swarthmore.edu/images/d/de/Word_AccessibilityPane_Ex1.png)](https://kb.swarthmore.edu/wiki/File:Word_AccessibilityPane_Ex1.png) [![The "check reading order" error from the previous image is expanded, showing that a table should be checked for reading order. The bottom of the window explains why and how to fix it.](https://kb.swarthmore.edu/images/1/1c/Word_AccessibilityPane_Expanded.png)](https://kb.swarthmore.edu/wiki/File:Word_AccessibilityPane_Expanded.png)
  4. Stumped? Go to [Microsoft's instructions](https://support.microsoft.com/en-us/office/improve-accessibility-with-the-accessibility-checker-a16f6de0-2f39-4a2b-8bd8-5ad801426c7f) for more detail, [Google your question effectively and efficiently](https://support.google.com/websearch/answer/134479?hl=en), or ask [the accessibility team](mailto:accessibility@swarthmore.edu)!
