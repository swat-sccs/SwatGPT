# Feature Story Callout Component

[← Return to the Drupal User Guide](https://kb.swarthmore.edu/wiki/Drupal_Home "Drupal Home")

The **Feature Story Callout** component is an eye-catching full-width component designed to highlight two featured stories or calls to action. This component can only be created and maintained by ITS administrators. 

To request that a **Feature Story Callout** component be added to your site, email [support@swarthmore.edu](mailto:support@swarthmore.edu).
